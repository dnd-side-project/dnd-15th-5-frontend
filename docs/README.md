## 문서 수정 기준

- 공통 구조·책임은 아키텍처, 기능 동작은 기능 문서, 실행·설정은 개발 문서에 기록한다.
- 코드에서 바로 확인할 수 있는 파일 목록·수치와 중복 설명은 추가하지 않는다.
- 내용을 옮기거나 문서를 추가하면 이 목록과 참조 링크도 갱신한다.
